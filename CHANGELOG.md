# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

## [1.0.0] - 2024-01-15

### Agregado
- ✨ Autenticación de usuarios con JWT
- ✨ CRUD completo de ingredientes
- ✨ Generación de recetas con IA (OpenRouter LLM)
- ✨ Sistema de calificación de recetas (1-5 estrellas)
- ✨ Historial de recetas generadas
- ✨ Base de datos MySQL con Drizzle ORM
- ✨ Frontend con diseño Memphis vibrante
- ✨ Docker y Docker Compose para despliegue
- ✨ Pruebas unitarias con pytest (18+ tests)
- ✨ Favicon personalizado

### Mejorado
- 🎨 Interfaz de usuario con estética Memphis
- 🎨 Tipografía negrita, mayúsculas, con sombra paralela
- 🎨 Paleta de colores: melocotón, menta, lila, amarillo
- 📚 Documentación completa en README.md
- 🔒 Validación de autenticación en todas las rutas

### Corregido
- 🐛 Conexión correcta de formularios con endpoints
- 🐛 Manejo de errores en autenticación
- 🐛 Validación de datos en CRUD

## Formato de Versionado

Este proyecto sigue [Semantic Versioning](https://semver.org/).

### Tipos de Cambios

- **Agregado**: Para nuevas funcionalidades
- **Mejorado**: Para mejoras en funcionalidades existentes
- **Corregido**: Para correcciones de bugs
- **Eliminado**: Para funcionalidades removidas
- **Seguridad**: Para arreglos de vulnerabilidades
