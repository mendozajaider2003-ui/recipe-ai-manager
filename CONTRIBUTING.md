# Guía de Contribución

## Bienvenido a Recipe AI Manager

Este documento proporciona directrices para contribuir al proyecto Recipe AI Manager.

### Cómo Contribuir

1. **Fork el repositorio**
2. **Crea una rama** para tu feature (`git checkout -b feature/AmazingFeature`)
3. **Commit tus cambios** (`git commit -m 'Add some AmazingFeature'`)
4. **Push a la rama** (`git push origin feature/AmazingFeature`)
5. **Abre un Pull Request**

### Estándares de Código

- Usa Python 3.9+
- Sigue PEP 8
- Escribe tests para nuevas funcionalidades
- Documenta tu código

### Reportar Bugs

Usa GitHub Issues para reportar bugs. Incluye:
- Descripción clara del problema
- Pasos para reproducir
- Comportamiento esperado vs actual
- Screenshots si es relevante

### Solicitar Features

Abre un GitHub Issue con:
- Descripción clara de la feature
- Casos de uso
- Ejemplos de implementación si es posible

### Proceso de Review

Todos los PRs serán revisados antes de ser mergeados. Asegúrate de:
- Pasar todos los tests
- Tener cobertura de tests adecuada
- Seguir los estándares de código
- Actualizar la documentación

¡Gracias por contribuir! 🙌
